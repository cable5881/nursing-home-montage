叙影 · 本地视频工作台

当前浏览器还没有连接工作台。

服务正在运行。这个浏览器尚未建立访问会话，换浏览器、使用无痕窗口或清除浏览记录后可能出现此页面。

  1. 在项目文件夹中，双击 打开视频工作台.command；已有项目也可用本地工作台 → 打开工作台.command。
  2. 启动器会在默认浏览器打开完整地址；想换浏览器时，把启动器返回的完整地址复制过去。
  3. 连接成功后，可以收藏工作台。在服务持续运行、浏览器会话有效时直接访问即可。

浏览、配置和查看成品不需要 Agent 在线。新的视频制作需要 Agent 接手；它暂时离线时，已提交的任务会留在队列中。打开页面不会停止当前制作。
