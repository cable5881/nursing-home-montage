# Humanizer-zh 口播适配规则

每篇养老机构口播初稿完成后读取并执行。依据 [Humanizer-zh SKILL.md](https://github.com/op7418/Humanizer-zh/blob/f4518a8eab97b8bfebc66a89d34320a89bef6930/SKILL.md)（revision 2026-09-23）整理；本文件提供本任务所需的完整执行要求，不要求运行时联网或另外安装技能。源项目采用 MIT 许可，原许可见[Humanizer-zh MIT](licenses/Humanizer-zh-MIT.txt)。

## 编辑边界

- 优先保留独立信息、事实与确定程度，再处理表达。数字、否定、范围、条件、归因、时间与完成状态不能被润色改掉；不能新增人物、经历、案例、引文或服务承诺，也不能把相关写成因果、可能写成确定。
- 文体保持为面向中老年人的客观带看口播，不添加第一人称体验、个人感受、故事或对话制造“人味”。可以借鉴用户样本的句长、用词和自然衔接，不移入样本中的机构事实。
- 只改确有问题的表达。模式是检查线索，不是词语黑名单；已有具体作用的连接词、列举、排比、四字词、术语和标点可以保留，已经通顺的句子不用强改。

## 逐篇润色

1. 通读完整初稿，记住必须保留的事实、条件和本条主题，再改句子，不逐句孤立替换近义词。
2. 删除只预告下文的铺垫、无内容的问候、无依据的拔高、空泛赞美和重复收尾。承载具体信息的开场语境、限定和结尾咨询动作要保留。
3. 处理拖沓的重复开头、层叠长定语、缺主语或缺宾语的句子，以及妨碍理解的生造词；能用日常动词讲清的，不堆抽象名词。不得为了补主语而编出施事者。
4. 调整公式化假对比、强凑排比、戏剧性碎片和没有必要的悬念。句子长短随意思自然变化，保持连贯，不为追求短句把口播改成提纲，不靠堆口头禅表现口语化。
5. 对照材料和初稿，检查有没有新增、遗漏或强化主张；合并同义重复可以，删掉不同信息不可以。改连接词时，核对顺序、因果、同时发生和转折关系是否仍成立。
6. 再通读成稿，按[口播文案](narration.md)检查主题、开头语境和本人物的一分钟容量。明显偏短时，用当前材料补充相关有效信息后再润色，不用空话补回字数。最终配音时长仍须实测。

润色作为写作中的一步，只交付任务需要的最终文本，不默认附草稿、模式命中清单或自评分。不以字数下降或“AI味消失”证明效果。
