# 默认自适应封面

新任务默认 C 款青绿拼贴：固定描边人物、三张实地图、两行主标题、高亮与三枚标签、人物署名、底部完整院名。仅用本地代码，不调用 imagen/imagegen，不重生成人脸。开关与字段见 [计划格式](plan-schema.md)；运行与发布包见 [运行](runtime.md)。

## 内容和身份

01 是项目确认的固定头标（settings.cover.header_text），不随每条视频改写。02/03 合为一份 main_title，分两行展示，可明确 lines 或自动断行，保留原词高亮。04/05/06 是三枚可选不同文本的标签，必须共用同一字号；卡片分别伸缩。每张图优先对应标签，同机构内不完全对应可继续并记录来源。

07 署名直接读所选人物绑定的社媒名，缺失请用户指定，只要名字；固定人物和署名一起换。08/09 合为一个完整院名字段，只读核验后的 institution.name，不用 displayName，不省略地区、括号或机构类型。机构全称是本条输入，不与人物长期绑定。

照片来自本条同机构素材，可以从实际混剪视频提帧或取真实照片；素材有限允许复用同机构图，不借其他机构画面。计划逐槽保存 source、可选 time/crop/focus 和匹配说明。

## 排版与渲染

assets/covers/teal-adaptive/layout.mjs 是唯一字号／间距／边界来源（BOUNDS），交互 HTML 和离线生产共用，不在文档复制数值表。按真实字形边界测量，标题两行同字号、三标签同字号，院名最多两行；调整宽高、居中及字号，不拉伸字形或截断。达到下限仍溢出时改文案或明确调整布局。参考标题每行约 4–7 个汉字，实际以测量为准。

通用字体为包内黑体，项目 settings.cover.font 可显式覆盖；封面字体与正文手写字幕字体独立。已有 cover_portrait 优先复用；否则 HyperFrames 本地 remove-background 处理头像，缓存到人物私有目录，轮廓描边由 Canvas 生成。私有图像和绑定不进入公共模板。

cover.py 选图／提帧、准备输入和编辑器，cover_renderer.mjs 复用锁定 HyperFrames 浏览器运行时导出 PNG。运行 `montage.py cover <job>` 会生成 cover.png、cover.json、cover-editor.html 并重新 compose。PNG 和 HTML 必须与输入指纹一致，布局通过后才能渲染。

## 视频首帧和覆盖

封面层只覆盖 [0,1/fps)，次帧回到正文原时间点；不插入片头秒数、不偏移音频和字幕。静态封面不改变正文首镜头运动视频要求，也不改变正文模板和字幕字号。

本次 settings.cover.enabled=false 可关闭；提供 settings.cover.image 时使用该 1080×1920 原图，否则自动生成。原图先显示在编辑 HTML，改动后按 C 款重排。封面／文字与原图需语义对应，由智能体核对。新封面导出后，需通过制作流程更新视频首帧；浏览器不会自动改包内 MP4。

输出为独立 PNG，并随最终 MP4、发布 TXT 与自包含编辑 HTML 一起进入发布 ZIP。内部 cover.json 合并输入、素材来源、布局诊断与哈希，不拆成多份清单。
