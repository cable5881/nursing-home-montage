# 版本更新

由当前 Agent 使用宿主提供的网络、文件或技能安装能力执行，用户无须逐条操作命令。仅检查时完成“查询”并报告；明确更新时继续下载、替换与验证。无需 Git 仓库或维护者的安装脚本；公开仓库可匿名读取。

## 官方来源与查询

- 唯一更新仓库：https://github.com/laoliAI666/nursing-home-montage
- 最新正式发布：https://api.github.com/repos/laoliAI666/nursing-home-montage/releases/latest
- 发布页：https://github.com/laoliAI666/nursing-home-montage/releases/latest

1. 从本次加载的 `SKILL.md` 实际路径定位安装目录，解析软链接；不凭固定用户名或宿主路径猜测，也不更新 `.montage/engines/` 中的任务快照。读取安装目录的 `VERSION` 与 `release.json`，两者须一致。若本次入口来自冻结引擎，应先定位宿主登记的可更新安装；无法确定目标时只报告缺项。
2. 查询 latest 接口，要求 `draft=false`、`prerelease=false`，且 `tag_name` 为 `vX.Y.Z`，三个版本段均为非负整数。正式版以该接口返回的 Release 为准，不以 main 分支、最新提交或仅有的 Git tag 替代。
3. 按三个整数比较版本，不按字符串排序。相同则报告已是最新版；本地版本更高则保留本地版并报告，不自动降级。仅检查时到此结束，附本地版本、远程版本和 Release 链接。
4. 未找到正式 Release、限流、无网络或读取失败时，区分具体原因并保留安装；不能将查询失败说成“已是最新版”，也不退回主分支下载安装。

## 下载与验证

从同一 Release 的 `assets` 中选择 `nursing-home-montage-vX.Y.Z.zip` 和 `SHA256SUMS`，使用 API 返回的 `browser_download_url` 下载到技能与项目目录以外的临时目录。`SHA256SUMS` 必须有且仅有一条匹配该 ZIP 文件名的 SHA-256；实际文件哈希须一致。缺包、缺校验值或不一致时停止，不改现有安装。

解压前检查条目不越出临时目录，且不含软链接。运行包须只有一个 `nursing-home-montage/` 根目录，包含 `SKILL.md`、`VERSION`、`release.json`、`preset.json`、`scripts/`、`references/`、`modules/`、`assets/`；不得含 `.git/`、`.montage/`、凭据或用户作品。核对 skill 名称仍为 `nursing-home-montage`，包内两个版本与 Release tag 一致，检查新入口的本地文档链接。

读取 `minimum_python`、`config_schema` 并与当前环境、实际项目配置核对。没有项目配置不妨碍更新；存在格式差异时使用该正式版明确提供的迁移方式，否则保留安装并报告缺少迁移能力。不能靠重建或重置项目配置完成升级。验证完再使用新版文档，不在校验前执行下载包中的代码。

## 保留与替换

1. 先将执行所需的步骤和版本信息留在安装目录外，等待当前安装相关的写入操作结束。记录目标真实路径和版本，在同一文件系统、宿主技能发现目录以外准备完整备份与候选目录；不要在技能搜索路径里留下第二份可发现的 `SKILL.md`。
2. 有 `.git` 时检查已暂存、未暂存及未跟踪的改动；无 `.git` 时可与旧版正式运行包或已有可信文件清单比对。保留本地差异到外部备份，不静默覆盖；无法确认或合并本地改动时停止并报告具体冲突。若安装目录混有用户资料，先保留并说明需要分离的路径，不能直接整目录覆盖。
3. 人物、音色、凭据、素材、作品、项目 `.montage/` 和旧任务引擎均不在替换范围内。安装中的 Git 元数据和宿主管理文件也须保留；仅替换已核对的发行运行文件，清理由旧版发行清单确认已移除的运行文件，不盲删未知文件。优先使用宿主支持的技能更新机制；直接文件替换时先备份、再切换，失败则恢复备份，不合并出新旧混杂的运行目录。
4. 更新后回读实际安装目录，核对版本、必要文件和新入口的本地链接，并将安装的发行文件与候选包逐一比较哈希。验证失败则回滚，并验证恢复的旧版；若回滚也失败，保留备份路径并如实报告。保留成功更新的备份位置，便于恢复。
5. 新任务使用新版；已有任务继续使用绑定引擎。需要把旧任务升级到新引擎时，按[另存与恢复](revisions.md)另存工程，不在本次技能更新中顺带升级。

## 结果

报告旧版 → 新版、正式 Release 链接、更新的安装路径和验证结果；无更新、保留本地改动、失败或回滚时准确说明实际状态。重新读取新入口；宿主需要重新加载技能或新开会话时说明操作，不把磁盘替换成功说成当前会话已加载新版。仅更新与安装有关的本地状态，不改变作品认可记录。
